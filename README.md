# Membeder

대회에 같이 나갈 팀원을 모으고 일정과 공지를 관리하는 안드로이드 앱입니다. 2022년에 팀 프로젝트로 만들었고, 선린 디지털 콘텐츠 개발대회에서 동상을 받았습니다.

## 기능

- 이메일과 구글 계정 로그인
- 팀 만들기, 멤버 모집, 지원 수락과 거절
- 팀 일정과 할 일 관리
- 공지 작성, 멤버 권한 관리
- 팀 채팅
- 대회 정보 보기

## 기술

Kotlin, XML 레이아웃, Retrofit, Coroutines, Navigation, Glide, Firebase

## 실행

Android Studio로 열어서 실행합니다. minSdk 26입니다.
